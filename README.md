# Linux for Embedded Systems 🐧

This repository contains my practical Linux learning and hands-on practice as I prepare for a career in **Embedded Systems Engineering**.

The goal is to build a strong understanding of Linux fundamentals and learn how Linux is used in embedded development.

## 📚 Learning Roadmap

I am following a focused 11-step Linux roadmap:

1. **Linux Basics**
2. **Files & Directories**
3. **File Contents**
4. **Permissions**
5. **Users & Groups**
6. **Processes**
7. **Package Management**
8. **Networking**
9. **Shell Scripting**
10. **Linux + C**
11. **Mini Projects**
